### 2º semestre — EcoByteMetrics

**Repositório:** [pentascripts-organization/EcoByteMetrics](https://github.com/pentascripts-organization/EcoByteMetrics)

Projeto desenvolvido durante o segundo semestre, com foco no monitoramento de serviços e na análise de consumo energético e emissões de carbono.

**Atividades desenvolvidas:**
- Desenvolvimento de funcionalidades do backend com Node.js e TypeScript.
- Implementação de rotas, controllers, services e repositories.
- Integração com APIs externas de métricas e intensidade de carbono.
- Persistência e consulta de dados utilizando PostgreSQL.
- Implementação de cálculos de consumo energético e emissões de CO₂e.
- Desenvolvimento de endpoints para estatísticas e rankings.

**Tecnologias utilizadas:**
- Node.js
- TypeScript
- Express
- PostgreSQL
- Docker
- APIs REST
